## 👋 About

Hi, I'm **M. Dhany Saputra** — known online as **dhasap**. I'm based in Indonesia and I like building practical software that solves everyday problems: Android apps, web dashboards, automation pipelines, scraping tools, networking utilities, and AI-assisted developer tooling.

Most of my public repositories are experiments that became useful tools: from a privacy-focused Android authenticator, IPTV/EPG automation, modular streaming apps, and MCP tooling, to Web3 minting automation and small Vercel/Node/Python utilities.

```txt
Focus: ship useful tools, automate repetitive work, and keep learning in public.
```
